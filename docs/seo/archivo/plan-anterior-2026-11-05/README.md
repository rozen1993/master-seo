## Trazabilidad y recuperación

[traslado.json](traslado.json) registra cada ruta original, ruta archivada, tamaño y SHA-256, junto con la huella de los 61 archivos de fase 6 antes del traslado. [verificacion-archivo.json](verificacion-archivo.json) recoge el resultado posterior.

La fase 6 no se editó. Sus manifiestos describen ubicaciones históricas y no se reescriben para simular que estos archivos nunca se movieron. Para verificar una fuente trasladada, usar el hash original y la ruta archivada del registro. El nuevo `docs/seo/00-traspaso.md` es un acceso breve y el nuevo `CLAUDE.md` apunta al plan vigente; sus versiones anteriores completas están aquí.

La operación es reversible: las rutas y contenidos anteriores están registrados. Una restauración debe conservar primero los nuevos accesos o cualquier trabajo posterior y comprobar colisiones antes de mover archivos; no sobrescribir cambios ajenos.
